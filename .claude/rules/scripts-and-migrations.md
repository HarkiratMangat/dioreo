## The per-script catalogue lives in `docs/reference/scripts-catalogue.md`

🔴 **Moved there 2026-09-09 17:52 EDT, and the reason is what this file costs rather than what it says.** Every section below this line used to be one section per script — 33 of them — and a path-scoped rule injects **in full** on any `Read` of a matching file. At 114,403 bytes this single rule was about a fifth of the entire tier, arriving whole because somebody opened a script. A catalogue is a lookup, and a lookup should cost nothing until it is asked for.

**What stayed here:** the pointer map above — which subsystem rule documents each script — and the traps that only matter once you are inside one (the backtick in a CSS comment inside a JS template literal, `parseBlocks()` stripping HTML comments, the independent gates, and `vmstatus.sh` targeting stock macOS bash 3.2).

**What moved:** everything that reads *"here is what this script does"*. Its headings are the script names, so `ctx_search` over `docs/reference/scripts-catalogue.md` finds one in a call.

⚠️ **This split is a correction, not a mechanism.** The `.claude/rules/` size ratchet that would have kept it split was proposed and rejected on 2026-09-02, so nothing prevents the catalogue being written back into this file one section at a time. That is exactly how it got to 114KB.
