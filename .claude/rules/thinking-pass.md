# The thinking pass — HOW, not just when

The HOW was written down nowhere, so he has supplied it by hand, every session, for over a month.*

## The pass, in his words

1. **Pre-emptively, not afterwards.** Before the work, not as a verification ritual after it. *"invoke and use sequential thinking frequently and pre-emptively, not afterwards"* (2026-08-27).
2. **Do not UNDERUSE it — that is the whole point, and the number is not the rule.** Harkirat, 2026-09-06 14:58 EDT, correcting this line: *"15+ thoughts is for a large, basically end of session run. every run doesnt need 15+ thoughts. the key insight is to not underuse the tool."*
   - **Length follows the question.** A fork between two known options is a few thoughts. A plan, an audit, a compact-prep or an end-of-session review is where 15+ belongs.
   - **One thought is never a pass.** *"Not once have i ever seen a session use it for 1 thought."* A single thought is a label on a conclusion already reached.
   - ⚠️ **Do not turn this into a quota.** Padding to a number is the same failure as skipping it — both substitute a count for the work.
3. **Question everything harshly.** Attack the premise, not only the plan built on it.
4. **Challenge your own thoughts** as they arrive. Steelman the objection to your own answer before presenting it.
5. **Ask the unasked question.** The one nobody in the thread has raised, including him.
6. **Check the unconsidered angle.** Name the angles NOT taken, then take one.
7. **Find gaps and staleness.** His most-repeated clause. Assume something you are relying on has already been superseded, and go look rather than recall.
8. **Falsify yourself.** Construct the case that shows you are wrong. A check that cannot fail is not a check.
9. **Do not re-ask what he already answered.** *"Don't ask questions that are just rephrased versions of things"* already settled.

## A third failure mode, found by actually running the pass — 2026-09-07 12:26 EDT

*Not theorized — measured in one real handoff-prep pass, with Harkirat pushing back three separate times before it held. Distinct from the two failure modes below: those are about WHEN a pass runs; this is about what makes a pass that DID run before the deadline STILL fall short.*

- 🔴 **STOPPING AT A PLAUSIBLE COUNT IS NOT THE SAME AS RUNNING OUT OF QUESTIONS.** A pass stopped at 11 thoughts — inside "10-15+," short of the stated "15+ at least" — because momentum moved to executing fixes, not because the questions ran dry. Pushed to continue, thought 13 (past where it had already stopped once) was the sharpest of the whole run. **The number was never the point; treating a number as sufficient is the failure.** The only real stopping signal is the LAST few thoughts finding nothing the FIRST few didn't — never a count.
- 🔴 **AN INTERRUPTION IS NOT A COMPLETION.** Real messages arriving mid-pass with unrelated, legitimate corrections got handled correctly — and the pass was then silently treated as done because forward motion had moved on to writing the deliverable. **A pass interrupted by reactive work needs an explicit RESUME, stated as such, not an implicit close.**
- 🔴 **"DID I VERIFY X" QUESTIONS ARE CORRECT AND NECESSARY — AND MUST NOT BE THE WHOLE PREMISE.** Self-audit ("did I verify claim X I already made") is real work and found real defects. But it is not what "ask the unasked question" means. Harkirat, naming this directly: *"why 'did i verify X' questions are correct, they shouldnt be the entire premise of the sequential thinking run... uncomfortable, hard, harsh, provoking, scrutinizing, deep/rich questions are important and necessary as well."* The question that found the sharpest defect this run was neither — it was **"is there ONE thing underneath these N separate findings"**, asked only after the checklist-mode questions had been exhausted.
- 🔴 **A CLEAN UNIFYING NARRATIVE IS ITS OWN THING TO FALSIFY.** Reframing five mistakes into "one root cause" felt like insight and was itself not fully honest — one of the five instances didn't actually fit the unifying story, and folding it in anyway to make the write-up tidier was reaching for the cleaner narrative over the messier true one. **The pass that produces a satisfying unifying answer is not done; stress-test the unification itself before writing it down**, the same way any other claim gets stress-tested.

## Two failure modes this file exists to stop

- 🔴 **Thinking AFTER, to verify a conclusion already reached.** That is a ritual, not a pass. The thoughts must be able to change the answer, which means they run before it is formed.
- 🔴 **Dispatching an auditor instead of auditing.** *"Dispatching an auditor is not auditing"* — see [[feedback_substituting_the_near_neighbour]]. A subagent's report is input to your pass, never a substitute for it.

⚠️ **The tool is unrestricted, permanently, by his own measured decision.** Cost is not a reason to skip it and never was. The only reason it has been skipped is that reaching for it was left to memory instead of being written down as the default shape of any judgement call.
