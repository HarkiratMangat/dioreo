barMP/DMZ, a rule, then Add build · Bulk create.
buildThe build number is locked into the Label field.
codeCode comes first. Pasting it fills every attachment it can: the digit names the slot, and a digit–letter pair seen on another build of the same weapon names the attachment. Measured: same weapon, same pair, same attachment on all 413 pairs; 311 of 587 attachments refill from other builds, none wrong.
searchA slot the code knows but can’t name stays open, and its search lists only that slot’s attachments.
DMZDMZ builds take up to nine slots and no gunsmith code.
tierTier in AR takes the tier’s colour: gold for Best, blue fading through Top 3–5.
bulkThe paste is exactly what Export writes. Each build’s lines share a coloured rail; its result names the lines. Readable builds stage; an unreadable block stays listed and is skipped.
orderSlots list in the display order set 2026-07-21; the code’s digit only says which slot a pair fills.
