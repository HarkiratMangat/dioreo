G4

Armory manifest

Weapon groups. Hover a build, tick one, copy a code.

  • Set name a plate with a “Build name” eyebrow, two lines at most. The Add build field caps it at 32 characters (all-caps names fill two lines at 34)
  • Faults the weapon lists the builds to fix; hover or tap it for details. Each faulty cell carries an amber corner mark that names the problem on hover; a hatched right edge marks the build
  • Code one field with the copy button joined to it; the whole field copies. A faulty code is amber with a wavy underline
  • Attachments one quiet tag per name, wrapping freely; the slot shows on hover and in By slot
  • Examples ARGUS’s missing image; the names “Close quarters” (AS VAL) and “Ranked hardpoint” (BAL-27). PHARO’s “Coming Soon” is real
  • Board only ten MP weapons picked for variety; the portal lists all of them
