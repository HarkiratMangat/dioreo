Track and Board are both looking; Manifest is doing. So they aren't peers. The visual layer sits on top and switches; the Manifest is always beneath it, always editable. This becomes the standing shape of every realm — Season, Armory, Broadcast — so there is one thing to learn rather than three. The switcher only ever changes the top half.

Armory

same two layers, no time axis

Loadouts have no dates, so there is no Track — but the layering holds. The visual layer offers Rack (what exists, by category, with its real accent) and Coverage (what's wrong, by category). Coverage is the Armory's answer to the Track's defect flags: instead of overlaps and gaps in time, it surfaces missing images, unbadged builds, near-duplicate gunsmith codes and stale entries — every cell filters the Manifest below it. Real numbers throughout: 68 MP weapons, 125 builds, 7 categories, read from the same weapon index the site's /commands page uses.

Commit & diff

the highest-consequence screen in the portal

Everything staged converges here. Each operation shows a field diff and, where the change is something a player will see, the real Discord card before and after. A tier-3 operation cannot be committed until what it destroys has been exported — and because adminParser's export formats round-trip back through its own bulk parsers, that download is a genuine restore path, not a receipt. Live state is re-read at this moment, so anything that moved underneath you since staging is caught here, not silently overwritten.

Why commit is all-or-nothing: the whole set applies in one Mongo transaction. A half-applied changeset is the worst outcome available — the bot reads fresh on every interaction, so it would serve the broken middle state to real users within seconds. This premise is unverified and gets proven with a real two-document transaction on the M0 cluster before anything is built on it.
