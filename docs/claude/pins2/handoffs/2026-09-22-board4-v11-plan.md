## 9 · Definition of done and what can make this wrong

- An item closes only with its state rendered full size and looked at, its class counted (found N / changed N), anything moved hit-tested and clicked, and every surface its classes reach re-rendered. Options close as **"built as A/B/C, awaiting his pick"**, never "done".
- **Scale** is the main risk: twelve half-finished options instead of four finished forks. The shared layer is finished and verified first; an option that cannot reach the bar is cut and the cut stated.
- **Design skills** run first (caveat 61652): `impeccable context` in T1, its craft floor before the first UI edit, inline (anchor #42).
- **Nothing is invented**: an unused-image source that does not exist is filed, not faked.
