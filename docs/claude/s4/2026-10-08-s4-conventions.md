## Names
- **C11 · Grammar** `type-size-shape.style-value--flag`: `-` picks one value (a colour or a data source), `--` adds a part that is there or not. A colour value goes on the element that takes the colour (a realm token on the in-field buttons, measured 2026-10-08 12:38 EDT). The value names the colour's family: `del` (the danger fill) reads `danger`, `danger-ink` reads `danger` (2026-10-08 18:42 EDT). A realm-coloured value reads `-realm`, never the realm's own name, as `-cat` stands for any category (his Q6 note, 2026-10-09 22:30 EDT: "instead of `-armory`, let's do `-realm`"; written 2026-10-10 19:21 EDT). · **-cat** names the item's weapon-category colour (his gunsmith code: paint-cat--quiet, 2026-10-11 20:02 EDT).
